VIVEFOOTTV — CATÁLOGO DE CANALES (VERSIÓN INICIAL SIN ADMIN)

INSTALACIÓN GITHUB PAGES
1. En el repositorio de www.vivefoottv.com, crea la carpeta partidos-en-vivo.
2. Sube index.html, ver.html, style.css, app.js y la carpeta assets dentro de ella.
3. Revisa la publicación: https://www.vivefoottv.com/partidos-en-vivo/
4. No reemplaces el index.html de la raíz del sitio.

EDITAR CANALES
En assets/channels.json puedes cambiar name, url, category, brand, theme y active.
Cada canal tiene un identificador único (canal-01, canal-02, etc.).
Aunque los nombres se repitan, sus páginas funcionan por ID.
Los 26 enlaces facilitados se han incorporado SIN VERIFICAR.

PUBLICIDAD
Los espacios marcados son placeholders: NO hay anuncios de una red configurados ni se garantiza pago al pulsar Play.
Una integración real requiere el código y las políticas de una red de anuncios aprobada.

REPRODUCCIÓN
La reproducción solo se intenta cuando el usuario pulsa Play.
HLS.js se carga desde jsDelivr; el reproductor necesita acceso a la biblioteca.
Los enlaces HTTP no se pueden reproducir normalmente dentro de una web HTTPS.
CORS, tokens, DRM, disponibilidad y restricciones del proveedor pueden impedir reproducir otros enlaces.
Los enlaces con 'parámetros ocultos' no están completos y no se han inventado parámetros.
No se permite eludir DRM o restricciones. Publica solo señales que tengas derecho de integrar.
Los rótulos LISTADO no afirman que la señal esté actualmente transmitiendo.
