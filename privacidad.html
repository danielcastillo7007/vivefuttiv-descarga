Política de privacidad de ViveFutTIV

Actualización: 22 de octubre de 2026.

Responsable y contacto

Aplicación ViveFutTIV, paquete Android com.vivefuttiv.app. Responsable legal: Daniel Castillo. Contacto de privacidad y solicitudes: vivefuttiv.soporte@gmail.com.

Alcance de la aplicación

ViveFutTIV es una aplicación para consultar noticias e información deportiva. No exige crear una cuenta para leer contenido, ni crea perfiles personales de lectores ni mantiene una base de datos propia de nombre, correo electrónico o contraseña de los lectores. La app no realiza análisis propios de comportamiento de usuarios. Estas afirmaciones no significan que no exista tratamiento de datos técnicos por parte de proveedores externos.

Datos y finalidades

La aplicación consulta servidores y servicios externos para mostrar noticias, calendarios, datos deportivos y transmisiones que se encuentren habilitadas. Estas conexiones pueden transmitir datos técnicos como dirección IP, información sobre solicitudes y registros de seguridad a los servidores o proveedores correspondientes.

Se guardan localmente favoritos, cachés y preferencias mediante WebView y almacenamiento del dispositivo para mejorar la experiencia y reducir las consultas. No se ha identificado un registro de cuentas de usuario para lectores en el código Android analizado.

Servicios técnicos de terceros

ViveFutTIV utiliza servicios externos necesarios para consultar y presentar información deportiva. Las solicitudes de red pueden comunicar a dichos servicios la dirección IP, datos técnicos del dispositivo, registros de funcionamiento y la información necesaria para entregar los contenidos. Algunos componentes integrados en la aplicación pueden procesar identificadores y datos de diagnóstico según estén configurados y activos. ViveFutTIV no utiliza estos datos para crear una base de datos propia de perfiles de lectores. El tratamiento realizado por cada proveedor está sujeto a sus condiciones y políticas de privacidad.

Datos que no solicitamos directamente

La lectura de noticias no requiere que el usuario facilite nombre, correo, número de teléfono, contraseña, contactos, fotos o ubicación precisa. Al comunicarse voluntariamente por correo con el soporte, se tratará la dirección y el contenido del mensaje para responder a la solicitud. La recopilación de datos por sitios y proveedores externos es independiente de esta recogida directa.

Notificaciones

Si permites notificaciones, la aplicación puede mostrar avisos relacionados con el fútbol. Puedes desactivarlas desde los ajustes de Android.

Fuentes y enlaces de terceros

Las noticias pueden abrir sitios web de terceros en la propia aplicación; esos sitios pueden utilizar cookies y aplicar sus propias políticas de privacidad. Las conexiones con servicios de noticias, datos, vídeos y Supabase también se rigen por las condiciones de los proveedores correspondientes.

Conservación y seguridad

Los favoritos, preferencias y las cachés locales pueden eliminarse al borrar los datos de la aplicación o desinstalarla. La conservación de registros en los servicios externos está sujeta a sus políticas y plazos de retención; el responsable no controla directamente esas bases de datos. Las comunicaciones y los datos tratados deben protegerse con medidas adecuadas a su naturaleza.

Derechos y solicitudes de eliminación

Para consultas, acceso, corrección o eliminación de datos personales, escribe a vivefuttiv.soporte@gmail.com. La eliminación de datos locales no implica la eliminación automática de datos conservados por terceros.

Cambios

Esta política podrá actualizarse cuando cambien proveedores, funcionalidades o requisitos legales. La versión pública debe mantenerse accesible desde la aplicación y en un sitio web.
